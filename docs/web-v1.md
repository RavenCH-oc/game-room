# 網頁版第一版（web v1）說明

這份文件是「伺服器 + 網頁畫面」第一版的實作依據。遊戲規則本身仍以 `docs/ctf-rules.md` 為準，這裡只講房間、連線和畫面。

文件沒寫到的情況，請先提問，不要自行決定。

## 1. 目標

在自己電腦上開兩個瀏覽器分頁就能玩一場 1v1 奪旗，也可以一個人跟範例 AI 打。

畫面先求清楚能玩，不求好看。美化是之後的事。

## 2. 技術

- `server/`：Node.js，用 `ws` 套件做即時連線。同一個伺服器也負責把網頁檔案送給瀏覽器，只開一個連接埠（預設 3000，可用環境變數 `PORT` 改）。
- `web/`：TypeScript，用 Vite 打包。不使用前端框架（React、Vue 等）。
- 規則結算一律呼叫 `games/ctf/core/`，伺服器和網頁都不能自己重寫規則。
- 伺服器的可調數字（第 8 節）集中放在一個設定檔。
- 這次允許新增的套件：`ws`、`vite`，以及它們需要的型別套件。其他要加的話在 PR 說明寫原因。

## 3. 大廳

- 進入網頁先輸入暱稱（1 到 12 個字，存在瀏覽器裡，下次自動帶入）。
- 兩個選擇：
  - **開房間**：選對手是「等朋友」、「AI：搶旗」或「AI：亂走」。
  - **加入房間**：輸入 4 碼房號。
- 房號是 4 個大寫英文字母，排除容易看錯的 I 和 O。
- 開房的人是 A 隊（左邊），加入的人是 B 隊（右邊）。AI 對手一律是 B 隊。
- 房間滿了、房號不存在、比賽已經開始：顯示白話的錯誤訊息，留在大廳。

## 4. 房間流程

1. **等待**：開房的人看到房號，等對手加入。選 AI 對手則跳過這一步。
2. **倒數**：兩邊到齊後倒數 3 秒開始。
3. **比賽**：見第 5 節。
4. **結束**：顯示誰贏、結束原因（對應規則第 6 節的六種）、最終分數和擊倒數。有「再來一場」和「回大廳」兩個按鈕。
   - 真人對戰：兩邊都按「再來一場」才重新開始。
   - 對 AI：按了就重新開始。

## 5. 比賽中的回合

- 計時由伺服器負責，網頁上的倒數條只是顯示。
- 每回合 3 秒（讀 `games/ctf/core/config.ts` 的回合秒數）。
- 所有「在場」的真人角色都送出動作後立刻結算。倒地離場中的玩家不用送，也不用等他。
- AI 的動作由伺服器在結算時呼叫腳本取得，不用等。
- 結算前可以改動作，以最後一次為準。時間到沒送視為「不動」。
- **對手的動作在結算前不能送到另一邊的瀏覽器。** 只能告訴對方「對手已經選好了」。
- 結算後，伺服器把新場面和事件清單送給兩邊。
- 伺服器要檢查收到的每個訊息：格式不對、不是這個房間的人、不是自己的角色，一律忽略，不能讓伺服器當掉。

## 6. 畫面

### 必須顯示

- 9×9 場地：牆壁、兩個重生點、旗子、兩個角色。
- 兩隊用顏色區分（A 隊藍、B 隊紅），自己的角色要有明顯標記。
- 每個角色的生命值（三格）。
- 持旗者身上要看得出拿著旗子。
- 無敵中的角色要看得出來（例如閃爍或外框）。
- 分數、擊倒數、目前回合數、是不是延長賽。
- 這回合剩餘時間的倒數條。
- 自己目前選的動作，以及「對手已選好」的提示。
- 自己倒地時：顯示還要幾回合重生。
- 最近幾回合發生的事（文字紀錄，例如「你打中對手，對手剩 2 點生命」）。

### 操作

滑鼠／觸控：

- 點自己旁邊的格子：往那邊移動。
- 按「射擊」按鈕後，再點上、下、左、右任一方向的格子：往那個方向射擊。
- 「放下旗子」按鈕：只有拿著旗子時能按。
- 「不動」按鈕。

鍵盤：

- W A S D：移動
- 方向鍵：射擊
- F：放下旗子
- 空白鍵：不動

拿著旗子時，射擊按鈕和方向鍵要停用並顯示原因。

### 動畫

- 第一版只要能看懂發生什麼事：角色位置直接更新，射擊畫一條短暫的線，被打中閃一下。
- 不做複雜動畫。

## 7. 斷線

- 玩家斷線後，他的角色每回合視為「不動」，比賽照常進行。
- 30 秒內用同一個瀏覽器重新整理或重新開啟，可以回到原本的房間和角色。
- 超過 30 秒沒回來：比賽結束，對手獲勝，結束原因顯示「對手離開」。這是伺服器層的判定，不要改動遊戲核心。
- 兩邊都離開：房間刪除。
- 比賽結束後 5 分鐘沒人按任何按鈕：房間刪除。

## 8. 伺服器設定

| 參數 | 數值 |
|---|---|
| 連接埠 | 3000 |
| 開始前倒數 | 3 秒 |
| 斷線等待 | 30 秒 |
| 結束後房間保留 | 5 分鐘 |
| 同時房間數上限 | 50 |
| 暱稱長度 | 1 到 12 個字 |

## 9. 指令

- `npm run dev`：開發用，一個指令同時啟動伺服器和網頁，改程式會自動更新。
- `npm run build`：打包網頁。
- `npm start`：用打包好的檔案啟動伺服器（之後給朋友連線用）。

啟動後終端機要印出可以直接點的網址。

## 10. 必須涵蓋的測試

房間邏輯要能在不開瀏覽器、不真的等 3 秒的情況下測試（用假的計時器）：

- 開房、加入、房號不存在、房間已滿。
- 兩邊到齊才開始；對 AI 直接開始。
- 兩邊都送出就立刻結算；只有一邊送出要等到時間到。
- 沒送出的視為不動。
- 倒地離場中的玩家不用送出也會結算。
- 送給某一邊的資料裡不包含對手還沒結算的動作。
- 亂七八糟的訊息不會讓伺服器當掉。
- 斷線後 30 秒內重連回到原角色；超過 30 秒對手獲勝。
- 再來一場：真人對戰要兩邊都同意。

畫面部分不用寫自動測試，在 PR 說明寫出你實際手動試過哪些操作。

## 11. 這一版不做

- Discord 整合、登入帳號
- 讓外面的人連進來（通道工具）
- 觀戰、聊天
- 2v2、3v3
- 美術素材、音效、Live2D
- 手機版面的細部調整（但操作必須能用點的完成，不能只靠鍵盤）
- 戰績紀錄、資料庫
